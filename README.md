# Real-Time-Skill-Cooldown-Performance-Simulator
A sandbox to practice PHP, Python and JS
## Skill Simulation System

A small event-driven simulation demonstrating frontend state management,
backend evaluation logic, and configurable parameters.

### Tech
- JavaScript (event-driven UI logic)
- Python FastAPI (stateless evaluation service)
- PHP (admin configuration)

### Key Concepts
- Deterministic state updates
- Decoupled event systems
- Metrics-based skill evaluation
